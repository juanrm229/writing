Meja Penulis

Masuk untuk menulis.

Panel ini menyimpan tulisan dan pengaturanmu langsung ke repo GitHub. Setiap kali kamu menekan Simpan, GitHub Pages memperbarui situs dalam sekitar satu menit.

Cara membuat token (sekitar 2 menit)
  1. Buka github.com/settings/personal-access-tokens/new.
  2. Beri nama, misalnya Meja Penulis, dan pilih masa berlaku.
  3. Di Repository access, pilih Only select repositories lalu pilih repo situs ini.
  4. Di Permissions → Repository permissions, atur Contents menjadi Read and write.
  5. Tekan Generate token, salin, lalu tempel di atas.

Token hanya disimpan di peramban ini dan hanya dikirim ke api.github.com.
