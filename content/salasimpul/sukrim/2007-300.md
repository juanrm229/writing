Saya tulis ini satu kali dan tidak akan saya baca lagi. @claims(p_sekali_melukai)

Tas di terminal. Perempuan, umur lima puluhan, duduk sendirian di bangku nomor tiga dari ujung. Tasnya ditaruh di sebelah, bukan di pangkuan. Itu sasaran.

Saya kira isinya dompet.

Ternyata isinya obat sama surat-surat rumah sakit sama satu amplop.

Suratnya saya baca di belakang loket. Itu kesalahan saya. Kalau tidak saya baca, saya bisa buang saja dan sudah.

Nama orangnya ada di situ. Tanggal kontrolnya ada. Sisa dosisnya ada.

Saya buang tasnya di kali begitu tahu. Saya tidak ambil apa-apa. Uangnya tidak saya sentuh; ada seratus dua puluh ribu di amplop itu dan saya tidak sentuh.

Tapi tasnya sudah tidak ada, dan orangnya sudah kehilangan, dan tidak ada gunanya saya tidak mengambil apa-apa. @protected

Saya balik ke terminal tiga hari berturut-turut. Saya cari mukanya. Saya sudah siapkan mau bilang apa — bohong, tentu; saya mau bilang saya nemu tasnya di kali, tapi isinya sudah hilang.

Saya bahkan sudah beli tas bekas yang mirip, buat jaga-jaga kalau perlu ditunjukkan.

Tidak ketemu. Orang itu sudah pergi, entah ke mana, entah bagaimana.

Dua puluh empat tahun saya bilang sama diri saya sendiri bahwa saya cuma ambil yang kecil-kecil, yang orangnya masih bisa beli lagi besok. Itu seluruh pembelaan saya. Itu satu-satunya yang saya punya. @irony(p_curi_kecil)

Yang satu itu merusak pembelaannya.

Dan yang paling jelek: saya tetap mencuri sesudahnya. Bulan depannya saya ambil jemuran. Bukan karena saya lupa. Karena tangan saya lebih cepat dari kepala saya, dan itu bukan alasan, itu cuma keterangan.

Kalau nanti ada yang tanya kenapa saya tidak pernah berhenti, jawabannya bukan karena saya tidak mau. @protected @irony(p_tangis, p_tisu, p_kue_jumat)

Tas bekas yang saya beli itu masih ada di kolong. Sudah tiga tahun.

Saya tidak tahu kenapa tidak saya buang. @protected
