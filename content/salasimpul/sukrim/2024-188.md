Saya yang masuk pertama. Saya mau bangunin buat sarapan.

Saya tidak langsung tahu. Saya panggil dua kali dulu, biasa saja, seperti tiap pagi.

Baru waktu saya pegang tangannya saya tahu.

Saya duduk di lantai di samping dia sampai Bu Inah lewat pagar. Saya tidak nangis. Saya cuma pegang tangannya.

Bukan karena kuat. Karena saya sudah tahu ini akan datang sejak Maret, dan sembilan bulan itu saya pakai buat nangisnya duluan, sedikit-sedikit, tiap malam, sesudah dia tidur.

Hampir setahun sejak saya pulang. Saya hitung malam ini: tiga ratus tiga puluh tiga hari.

Empat tahun di penjara saya bayangkan pulang, dan yang saya dapat cuma tiga ratus tiga puluh tiga hari.

Saya sudah pikir-pikir dan saya tidak berani marah sama siapa-siapa soal itu, sebab yang menghabiskan empat tahun itu saya sendiri.

Saya berhenti menghitung mundur jam sebelas tadi. Tidak ada ujungnya. @protected

Rumahnya bersih waktu dia pergi. Itu saja yang saya punya.

Rumahnya bersih dan hangat dan ada bunga curian di mejanya dan lantainya baru saya pel kemarin.

Bunganya saya ambil dari pagar orang tiga rumah dari sini. Saya tidak akan bohong soal itu di buku ini.
